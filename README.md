## Featured project

### 📄 [RAG Document Knowledge Assistant](https://github.com/aabdu1lah/rag-document-assistant)

Upload PDFs and ask questions in plain English. Every answer is grounded in your documents and shown with the exact source excerpts it came from. If the answer isn't in your files, the assistant says so instead of guessing.

```text
PDF ➜ text extraction ➜ chunking ➜ embeddings ➜ PostgreSQL + pgvector
Question ➜ embedding ➜ similarity search ➜ top-5 chunks ➜ LLM ➜ cited answer
```

**Stack:** FastAPI · React · PostgreSQL + pgvector · OpenAI API or local LLMs via LM Studio
